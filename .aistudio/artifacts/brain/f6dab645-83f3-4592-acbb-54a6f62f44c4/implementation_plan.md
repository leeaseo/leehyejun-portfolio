# 관리자 페이지 드래그 앤 드롭 이미지 업로드 및 전체 순서 정렬 개선 계획

관리자 페이지(Admin Center)에서 사진을 첨부하거나 항목 순서를 조정할 때의 반복적인 클릭 피로도를 줄이기 위해, **모든 이미지 영역의 파일 드래그 앤 드롭(Drag & Drop) 즉시 업로드**와 **전 영역 마우스 드래그 순서 정렬(Reordering)**을 도입합니다.

### User Review & Critical Decisions

> [!IMPORTANT]
> 아래 3가지 핵심 동작 방식은 앞서 선택해 주신 답변을 바탕으로 확정된 설계 기준입니다.

- **확정 사항 1 — 모든 이미지 영역에 파일 드래그 앤 드롭(Dropzone) 적용**: `Photo 대표 촬영컷`, `Photo 최종 촬영 이미지 목록`, `More 탭 각 디벨롭 블록(#1, #2, #3...) 이미지 영역`, `추가 과정 보드` 등 모든 사진 등록 구역에 컴퓨터 폴더의 이미지 파일(단일/다중)을 마우스로 끌어다 놓아 업로드할 수 있습니다.
- **확정 사항 2 — 크롭 창 강제 팝업 없이 즉시 첨부 + 개별 크롭 옵션 유지**: 사진을 드롭하거나 파일 선택으로 올릴 때 매번 자르기 창이 가로막지 않고 **즉시 고화질로 첨부**되며, 필요할 때만 각 사진 위 오버레이의 **`[자르기(Crop)]`** 버튼을 눌러 구도와 비율을 다듬을 수 있습니다.
- **확정 사항 3 — 이미지·블록·스펙·프로젝트 전체 드래그 순서 변경**: 화살표(`↑`/`↓`, `←`/`→`)를 여러 번 누를 필요 없이 마우스로 잡고 끌어서(`Grip` 핸들 및 카드 드래그) **프로젝트 순서(1~9번), 상단 스펙 항목, 기여도 항목, More 디벨롭 블록 순서, 블록 내 사진 순서**를 한 번에 바꿀 수 있습니다.

### 1. Overview & Core Concept

- **What It Does**: 포트폴리오 관리자 모달 내의 모든 이미지 첨부 영역을 대화형 드롭존(Dropzone)으로 업그레이드하고, 리스트 및 그리드 형태의 모든 편집 항목에 HTML5 네이티브 드래그 앤 드롭 정렬을 적용합니다.
- **Target Audience / Persona**: 다수의 고해상도 가구·공간 촬영컷과 디벨롭 과정 이미지를 빠르게 배치하고 순서를 큐레이션해야 하는 포트폴리오 소유자(디자이너).
- **Key Value**:
  - 여러 장의 사진을 폴더에서 바로 끌어다 놓는 순간 크롭 모달 대기 없이 즉시 들어가므로 사진 등록 시간이 대폭 단축됩니다.
  - 첫 번째칸부터 끝칸까지 화살표를 반복 클릭하던 불편함 없이, 원하는 위치로 한 번에 드래그하여 순서를 바꿀 수 있습니다.

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **파일 드래그 앤 드롭 업로드 플로우**:
     - 사용자가 내 컴퓨터 폴더에서 사진 파일(1장 또는 여러 장)을 잡고 관리자 창의 원하는 이미지 영역(`대표 촬영컷`, `Photo 촬영컷 목록`, `More 블록 #1, #2... 이미지 영역`) 위로 가져갑니다.
     - 해당 영역 테두리가 블랙 점선 하이라이트(`border-black bg-neutral-100/80`)로 반응하며 `"여기에 놓아 사진 즉시 추가"` 안내가 표시됩니다.
     - 마우스를 놓으면 크롭 창 팝업 없이 즉시 원본 비율(고화질 최적화)로 목록에 추가되고 백그라운드 자동 저장이 수행됩니다.
     - 비율 수정이 필요한 사진만 썸네일 우측 하단의 **`[자르기]`** 아이콘을 눌러 기존 크롭 모달을 열 수 있습니다.
  2. **드래그 앤 드롭 순서 변경 플로우**:
     - **Work 프로젝트 순서**: 상단 프로젝트 선택 탭 바(또는 목록 보기)에서 프로젝트 칩을 드래그하여 놓으면 `order` 번호(`#1`, `#2`...)가 즉시 재계산되어 정렬됩니다.
     - **More 스펙 항목 & 기여도 항목**: 각 줄 좌측의 드래그 핸들(`GripVertical`)을 잡고 위아래로 끌어 순서를 맞춥니다.
     - **More 디벨롭 과정 블록(`BLOCK #1`, `BLOCK #2`...)**: 블록 상단 헤더를 잡고 위아래로 드래그하여 블록 전체의 순서를 바꿉니다.
     - **블록 내부 이미지 및 Photo 촬영컷**: 썸네일 카드를 마우스로 끌어 원하는 칸에 놓으면 즉시 대표(`1.1`) 및 서브 이미지 순서가 바뀝니다.

- **Visual Identity & Theme**:
  - *Aesthetic Direction*: 기존 포트폴리오의 모노크롬 에디토리얼 톤앤매너(Crisp White `#FFFFFF`, Warm Surface `#FAFAFA`, Stark Black `#000000`)와 일관된 미니멀 어드민 인터페이스.
  - *Interactive Feedback & Motion*:
    - 파일 드래그 오버 시: `border-2 border-dashed border-black bg-neutral-900/5` 시각적 하이라이트.
    - 항목 드래그 중: 이동 중인 카드는 `opacity-35 scale-95 border-dashed border-black`, 놓일 대상 위치(Drop Target)는 `ring-2 ring-black scale-[1.01]` 하이라이트로 명확한 위치 피드백 제공 (보조용 화살표 버튼도 함께 유지하여 미세 조정 가능).

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: 파일 업로드 시 즉시 첨부(Direct Attach) 기본화 + 온디맨드 크롭(On-Demand Crop)**
  - *Chosen Approach*: 파일을 드롭하거나 선택하면 크롭 큐 모달을 자동으로 띄우지 않고 즉시 `compressImageFile`(2560px 고화질 유지)을 거쳐 배열에 추가하며, 각 이미지 카드의 `[자르기]` 버튼을 클릭할 때만 크롭 모달을 엽니다.
  - *Why*: 10~20장의 사진을 한꺼번에 올릴 때 크롭 창이 20번 연속으로 뜨면 작업 흐름이 끊깁니다. 즉시 첨부 후 필요한 컷만 선택적으로 크롭하는 것이 훨씬 빠르고 직관적입니다.
- **Decision 2: 외부 파일 드롭과 내부 순서 변경 드래그의 이벤트 분리**
  - *Chosen Approach*: `e.dataTransfer.types.includes('Files')` 여부를 감지하여, 외부 폴더에서 파일을 끌어온 경우에는 **파일 업로드 드롭존**으로 동작하고, 내부 카드를 드래그할 때는 **순서 정렬(Reorder)**로 동작하도록 충돌 없이 분리합니다.
  - *Why*: 동일한 이미지 그리드 위에서 '새 사진 파일 드롭 추가'와 '기존 사진 카드 드래그 순서 변경'이 모두 매끄럽게 작동해야 하기 때문입니다.

### 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:
```
┌───────────────────────────────────────────────────────────────────────────┐
│                         AdminPublishModal (UI)                            │
├───────────────────────────────────┬───────────────────────────────────────┤
│   File Dropzones (Files Drag)     │    Sortable Lists & Grids (Item Drag) │
│  ┌─────────────────────────────┐  │  ┌─────────────────────────────────┐  │
│  │ • Photo 대표 촬영컷 드롭존    │  │  │ • Work 프로젝트 순서 (1~9번)      │  │
│  │ • Photo 촬영컷 그리드 드롭존  │  │  │ • More 상단 스펙 항목 (Specs)     │  │
│  │ • More 블록별 이미지 드롭존   │  │  │ • More 기여도 항목 (Contribution) │  │
│  │ • 추가 과정 보드 드롭존       │  │  │ • More 디벨롭 블록 (#1, #2, #3)   │  │
│  └──────────────┬──────────────┘  │  │ • 블록 내부 이미지 & Photo 촬영컷  │  │
│                 ▼                 │  └────────────────┬────────────────┘  │
│     Direct High-Res Attach        │                   ▼                   │
│   (Optional On-Demand Cropper)    │         Array Splice & Re-index       │
└─────────────────┴─────────────────┴───────────────────┴───────────────────┘
                                    │
                                    ▼
┌───────────────────────────────────────────────────────────────────────────┐
│        Real-Time Auto-Save (IndexedDB + Cloud Firestore) & Publish        │
└───────────────────────────────────────────────────────────────────────────┘
```

- **Interactive Component & State Mapping**:
  - **파일 드롭 핸들러 (`processUploadedFiles`)**: 드롭되거나 파일 입력으로 들어온 `FileList`에서 이미지 파일만 필터링하여 병렬로 고화질 데이터 URL로 변환한 뒤 대상 상태(`thumbnail`, `detailImages`, `moreBlocks[bIdx].images`, `processImages`)에 즉시 반영합니다.
  - **드래그 정렬 상태 관리**:
    - `projectDragIdx` / `projectOverIdx`: `draftProjects` 배열 순서 변경 후 각 항목의 `order` 값을 `1, 2, 3...`으로 자동 재부여.
    - `specDragIdx` / `specOverIdx`: `customSpecs` 배열 내 스펙 행 순서 이동.
    - `contribDragIdx` / `contribOverIdx`: `contributionPhases` 배열 내 기여도 행 순서 이동.
    - `blockDragIdx` / `blockOverIdx`: `moreBlocks` 배열 내 블록 카드 순서 이동.
    - `blockImgDrag` (`{ blockIdx, imgIdx }`): 특정 블록 내부 이미지(`1.1`, `1.2`, `1.3`...) 순서 드래그 이동.
  - **자동 백업 연동**: 순서 변경이나 파일 드롭 첨부가 끝나는 즉시 기존 0.6초 디바운스 자동 저장(`IndexedDB` + `Firestore`)이 트리거되어 새로고침해도 변경된 순서와 사진이 그대로 유지됩니다.
